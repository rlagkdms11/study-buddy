### 손 실험: 설계패턴 1강 PDF
- 사용한 프롬프트
  - 기본: "대학생 복습용 정리본으로 만들어 줘(소제목, 굵게, ⭐, PDF에 없는 내용 추가 금지)" + "복습 퀴즈 10문항(객관식 7, 단답형 3, 정답·해설·근거 페이지)"
  - 개선: 예전에 시험공부에 썼던 HTML 노트 형식을 반영 (전체 지도, 공부 순서, 왜→그래서 흐름, 단서표, 비교표, 함정, 서술형 한 문장, 접히는 예상문제, ★ 중요도)

- 정리본에서 이해 안 된 부분: 쉬운 pdf 내용이어서 그런거 아직까지는 없었음
- 잘 된 점 / 문제점
  - 기본 프롬프트 결과는 평범한 문서형 정리본이라 그냥 pdf 보는 것과 별반 다르지 않음 
  - 개선 프롬프트 결과: 전체 지도, 공부 순서, 왜→그래서 흐름, 단서표, 비교표, 함정, 서술형 한 문장, 접히는 예상문제가 모두 들어가 예전 시험 노트 수준이 됨. 같은 내용을 깔끔/노트 두 스타일로 받아 보니 둘 다 쓸 만해서 스타일 선택(#8)이 필요하다는 근거가 생김
  - 남은 문제: PDF에 없는 비유가 추가됨(출처 구분 필요), 퀴즈가 서술형 위주로 바뀌어 기본 결과와 형식이 다름

### 결정한 것
- AI는 내용만 JSON으로 받고, 디자인은 앱의 고정 템플릿으로 그린다 (매번 모양이 같고 깨지지 않음, 스타일 선택 기능도 붙이기 쉬움)
- 정리본 형식은 예전 시험 노트 두 개를 기준으로 한다

## 10/27 (화) #2 첫 버전 1일차

- PyMuPDF로 PDF 페이지별 텍스트 추출 (설계패턴 1강, 10쪽)

| 시도 | 결과 | 문제 |
|---|---|---|
| 기본 get_text() | 글자 깨짐 없음 | 슬라이드 글 상자 순서가 뒤섞임 (목차 번호 01→03→04→02), 문장이 줄 단위로 쪼개짐 |
| get_text(sort=True) | 위치 순서는 맞음 | 나란한 글 상자끼리 줄이 섞임 ("이 강의에서디자인 패턴 디자인 패턴 GoF…") |
| 블록 단위 정렬 (채택) | 상자 안 문장은 유지, 상자끼리 위치 순서 | 번호 위치가 미세하게 어긋남, 단어 중간 띄어쓰기 → AI가 읽기엔 충분하다고 판단 |

- Gemini API 연결 (무료 등급으로 시작, AI 호출은 ai.py의 ask_ai 함수 하나로 분리해 나중에 다른 API로 바꾸기 쉽게 함)
- 문제와 해결

  - 503 서버 혼잡 → 자동 재시도(1초, 2초 대기) + 사용자용 오류 메시지 추가
  - 실수로 API 키가 보이는 화면을 캡처해 공유 → 키 삭제 후 재발급, 키는 secrets.toml에만 두고 .gitignore로 막는 것 확인
