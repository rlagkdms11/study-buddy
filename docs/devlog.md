### #15 퀴즈 화면
- 브랜치: feat/#15-quiz
- 풀기
  - 객관식은 보기를 눌러 고르고, 단답형은 직접 입력
  - 고를 때마다 브라우저에 바로 저장 → 새로고침하거나 정리본을 보고 와도 답이 남아 있음
  - 남은 문제 수 안내, 안 푼 문제가 있으면 한 번 더 눌러야 채점
- 채점
  - "n문제 중 m개 맞았어요", 문제마다 맞음/틀림, 정답·내 답 색 표시, 해설, 근거 쪽 번호

  - 그래도 맞았는데 틀렸다고 나오면 "맞은 걸로 할게요"로 직접 고침
  - 틀린 문제 번호와 점수를 Day 기록에 저장 (지난 공부·복습 날에 쓸 예정), 오늘 화면 진행 바에 반영
- 채점 후
  - 정리본에서 다시 보기: 문제의 섹션 이름으로 정리본의 그 단원으로 바로 이동, 잠깐 노란 테두리로 표시
  - 이해 안 돼요 / 정답이 이상해요: 문제에 표시만 저장 (시험 전날 "자주 막힌 개념"과 #4 설명 기능에서 쓸 예정)
  - 틀린 문제 다시 풀기: 틀린 문제만 다시 풀고 다시 채점
  - 새 퀴즈 만들기: 이전 퀴즈와 답은 기록으로 남기고 새로 생성
- 가짜 퀴즈로 풀기 → 새로고침 → 채점 → 다시 풀기 → 정리본 이동까지 확인
- 채점 후 링크 3개(정리본에서 다시 보기·이해 안 돼요·정답이 이상해요)가 해설 아래 흩어져 보여서 정리
  - 해설을 회색 상자에 넣고, 아랫줄 왼쪽에 "정리본 p.3에서 다시 보기 →", 오른쪽에 작은 칩 버튼 두 개
  - 칩을 누르면 주황색으로 바뀌어 표시했다는 게 보이게 함- "이해 안 돼요"는 지금 눌러도 표시만 저장되고 아무 반응이 없어 헷갈림 → #4 설명 기능을 만들 때까지 숨김

### #22 로딩·오류·밀린 날
- 브랜치: feat/#22-states
- 정리본·퀴즈를 만드는 상태를 Day별로 기억(prepState)해서 오늘 화면, 정리본 화면, 퀴즈 화면이 같이 씀
- 로딩: 정리본·퀴즈가 아직 없으면 빈 안내 대신 만드는 화면
  - 단계 표시(✓ PDF 글자 읽기 → ● AI가 정리본 쓰는 중 n초째 → ○ 퀴즈 만들기), 다 되면 그 자리에서 바로 정리본·퀴즈를 보여 줌
  - 오른쪽 "기다리는 동안": 오늘 복습 퀴즈, 틀린 문제 다시 보기, 지난 공부
- 오류: "AI 서버가 지금 붐벼요" + 다시 시도, 1분 뒤 자동으로 한 번 더 시도 (남은 초 표시), 내 자료와 기록은 그대로라고 안내
  - 서버 붐빔(503)이 아닌 오류는 서버가 준 한국어 메시지를 그대로 보여 줌
- 밀린 날: 오늘보다 앞선 날인데 퀴즈를 안 푼 Day가 있으면 오늘 화면 위에 안내
  - "어제(Day 2) 범위가 밀렸어요 · 다시 나누면 하루 분량이 약 5쪽 → 7쪽"
  - 남은 날로 다시 나누기 (설정의 "남은 범위 다시 나누기"와 같은 함수 replanRemaining) / 그대로 두고 밀린 것부터 하기 (오늘은 안내 숨김)
- 문제: "퀴즈을 만들지 못했어요" 조사 오류 → "퀴즈를 / 정리본을"로 나눔
- 가짜 AI(2.5초 대기, 실패 스위치)로 확인: 밀린 날 안내 → 정리본 로딩 화면 → 자동으로 정리본 표시 → 다시 나누기 → 오류 화면(59초 뒤 자동 재시도) → 다시 시도 → 퀴즈 표시
- 한계: 다시 나누면 퀴즈를 안 푼 Day의 범위가 바뀌어서, 미리 만들어 둔 그날 정리본은 새로 만들어야 함- 오늘 화면도 넓게: 밀린 날 안내는 맨 위 전체 폭(설명과 버튼을 한 줄로), 그 아래 왼쪽에 오늘 범위·진행·버튼, 오른쪽에 오늘 복습(없으면 복습 일정표)
