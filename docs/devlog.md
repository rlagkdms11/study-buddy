### #15 프론트엔드 시작: 자료 올리기 → 학습 계획 → 오늘
- web/ 폴더 (HTML·CSS·JS, 프레임워크 없음). FastAPI가 같은 주소에서 화면도 보여 줌
- 화면은 주소 뒤 #으로 나눔 (#/upload → #/plan → #/today)
- 자료 올리기: 파일을 고르자마자 서버가 읽어서 강의 순서와 쪽수를 보여 줌, 글자 없는 쪽 안내
- 학습 계획: 날짜를 바꾸면 바로 다시 나눔, 처음엔 3일만 보이고 "전체 보기", 스타일 카드 선택
- 오늘: 오늘 범위와 D-day, 화면을 열면 정리본 → 퀴즈를 미리 만들기 시작
  - 만드는 중에 다른 화면으로 가도 결과가 사라지지 않게 저장된 최신 기록에 합쳐서 저장
- 문제: 처음 주소(/)로 들어오면 #/upload로 바꾸는 사이 화면이 두 번 그려져 고른 파일이 사라짐 → 주소만 바꾸고 바로 그리도록 수정
- 가짜 AI 서버와 헤드리스 브라우저로 처음부터 오늘 화면까지 흐름 확인
- 실제 Gemini로 첫 연결 성공: 15쪽 범위 정리본 10초, 퀴즈 5초 (3.5 Flash Lite)

### #15 정리본 화면 (필기 스타일)
- 시안의 필기 노트를 지금 AI가 주는 JSON 모양에 맞춰 그림
  - 섹션 = 모눈종이 카드 + 쪽 번호 테이프 라벨(분홍·민트·하늘 돌아가며), 중요도 별
  - why → so는 빨간 점선 흐름 상자, 중요도 2 이상 핵심은 밑줄 + 형광펜
  - 함정은 "↳ 주의!" 빨간 손글씨, 단서는 표, 비유는 노란 메모, 확인 질문은 눌러서 펼치기
  - 중요도 3 핵심을 모아 "시험 직전 TOP", 비교표는 "헷갈리는 쌍"
  - 맨 위·맨 아래에 퀴즈 버튼
- 하루 범위가 두 강의에 걸치면 쪽 번호 앞에 "1강"처럼 강의 이름을 붙임
- AI가 칸을 빼먹어도 화면이 깨지지 않게 모든 칸을 비어 있을 수 있다고 보고 그림
- 아직 없는 것: "↳ 왜?"(시험에 나오는 이유) 칸은 프롬프트에 why_exam을 추가해야 함, 깔끔 스타일

### #15 첫 화면 넓게 바꾸기
- 브랜치: feat/#15-wide-layout
- PR로 캡처해 보니 자료 올리기·학습 계획이 휴대폰 앱처럼 좁은 가운데 한 줄이라 노트북 화면에서 휑함
- 넓은 화면(900px 이상)에서는 두 칸으로 나눔
  - 자료 올리기: 왼쪽 큰 제목 + 사용 순서 3단계 소개 / 오른쪽 PDF 놓는 곳과 파일 목록
  - 학습 계획: 왼쪽 날짜 + Day별 계획(7일까지 바로 보임) / 오른쪽 스타일 카드(미리보기와 설명을 가로로)와 시작 버튼
- 좁은 화면에서는 전처럼 한 줄로 쌓임
- 서버가 꺼져 있을 때 브라우저 영어 오류("Load failed")가 그대로 보이던 문제 → "서버에 연결하지 못했어요" 한국어 안내로 바꿈

### #15 퀴즈 화면
- 브랜치: feat/#15-quiz
- 풀기
  - 객관식은 보기를 눌러 고르고, 단답형은 직접 입력
  - 고를 때마다 브라우저에 바로 저장 → 새로고침하거나 정리본을 보고 와도 답이 남아 있음
  - 남은 문제 수 안내, 안 푼 문제가 있으면 한 번 더 눌러야 채점
- 채점
  - "n문제 중 m개 맞았어요", 문제마다 맞음/틀림, 정답·내 답 색 표시, 해설, 근거 쪽 번호
  - 단답형은 띄어쓰기·대소문자·기호를 무시하고 비교 ("Private" = "private", "23" = "23가지")
  - 그래도 맞았는데 틀렸다고 나오면 "맞은 걸로 할게요"로 직접 고침
  - 틀린 문제 번호와 점수를 Day 기록에 저장 (지난 공부·복습 날에 쓸 예정), 오늘 화면 진행 바에 반영
- 채점 후
  - 정리본에서 다시 보기: 문제의 섹션 이름으로 정리본의 그 단원으로 바로 이동, 잠깐 노란 테두리로 표시
  - 이해 안 돼요 / 정답이 이상해요: 문제에 표시만 저장 (시험 전날 "자주 막힌 개념"과 #4 설명 기능에서 쓸 예정)
  - 틀린 문제 다시 풀기: 틀린 문제만 다시 풀고 다시 채점
  - 새 퀴즈 만들기: 이전 퀴즈와 답은 기록으로 남기고 새로 생성
- 가짜 퀴즈로 풀기 → 새로고침 → 채점 → 다시 풀기 → 정리본 이동까지 확인
- 채점 후 링크 3개(정리본에서 다시 보기·이해 안 돼요·정답이 이상해요)가 해설 아래 흩어져 보여서 정리
  - 해설을 회색 상자에 넣고, 아랫줄 왼쪽에 "정리본 p.3에서 다시 보기 →", 오른쪽에 작은 칩 버튼 두 개
  - 칩을 누르면 주황색으로 바뀌어 표시했다는 게 보이게 함
